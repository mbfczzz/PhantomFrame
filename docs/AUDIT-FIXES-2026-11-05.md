# 审计修复 2026-11-05

本次修复针对访问慢、任务调度逻辑和账户安全三类问题。回归测试见 `internal/api/audit_fixes_test.go`。

## 访问速度

| 问题 | 修复 |
| --- | --- |
| 创作页每 2 秒轮询，每次都重新签发 OSS 链接，浏览器反复重新下载全部结果图 | 签名链接在有效期过半前复用（`cachedOSSURL`）；`urlExpiresAt` 返回实际到期时间 |
| 空闲时也每 2 秒请求 `/jobs` | 只有排队/生成中的任务时快速轮询，空闲时 30 秒一次（`jobListInterval`） |
| `/jobs` 每个结果单独查询素材和存储配置 | `jobViews` 批量查询素材，存储配置每次请求只读一次；素材列表同样共享 |
| 无压缩、无静态缓存，部署后可能白屏 | Nginx 开启 gzip 与 HTTP/2；`/assets/` 一年 `immutable`，`index.html` 为 `no-cache`；缺失的哈希资源返回 404，不再回退到页面 |
| 列表排序无法使用索引、`assets.job_id` 无索引 | 启动时自动补建索引（见 `performance_migrations.go`） |
| 后台统计每 5 秒全表聚合 | 总数缓存 30 秒，后台写操作后立即失效；后台轮询放慢到 15–30 秒 |
| `/api/models` 每次重新组装 | 按目录版本缓存，任何后台写操作都会更新版本 |
| 大文件下载 120 秒被断开，素材文件 `no-store` | 文件下载单独放宽到 30 分钟，素材文件允许私有缓存 1 天 |
| API Key 每次请求写库 | `last_used_at` 每分钟最多更新一次 |
| 其他 | 数据库连接池空闲数与最大数一致；工单列表去掉 N+1；正则预编译；次要页面按需加载（主包 409 kB → 360 kB） |

## 任务调度

- 任务执行与 Redis 选主解耦：每个实例都执行任务，每个运行中的任务带 90 秒租约并由执行实例续期。维护实例只回收租约过期的任务，不再在选主切换或重启时把所有运行中任务全部退款。
- 选主续期失败会重试，只有确认租约已丢失或即将过期时才放弃维护职责。
- 并发可配置：`WORKER_CONCURRENCY`（默认 8）、`WORKER_PROVIDER_CONCURRENCY`（默认一半）。
- 停机时先等待 `WORKER_SHUTDOWN_GRACE`（默认 20 秒）；之后取消的任务若从未向上游发出请求则放回队列，否则按原规则退款。
- 上游已出结果后，OSS 转存有独立的 5 分钟预算并重试 3 次，写库重试 5 次，不再因接近截止时间或单次失败丢弃已付费的结果。
- 上游任务 ID 写库失败会重试并记录日志，不再直接让任务失败。
- 同步生成请求超时从 60/90 秒放宽到 10 分钟（仍受任务总时限约束）。
- 通用协议轮询按时间而非固定 180 次；偶发 5xx/429/网络错误退避重试；补充 `canceled`、`expired`、`rejected`、`timeout` 等失败状态。
- 供应商结果直接流式写入磁盘，不再整段读入内存；下载共用连接池，不再清空全局空闲连接。
- 提交任务时对模型行使用共享锁，ffprobe 等慢操作在加锁前完成，同一模型的提交不再互相排队。
- 渠道模型同步会刷新此前同步得到、且管理员未编辑、未发布的条目。

## 账户安全

- 修改密码、管理员变更角色/状态后，已有 API Key 一并失效。旧 Key 继承当前版本，升级后仍可用。
- 主账户停用后，其子账户不能登录或调用。
- 子账户每个主账户最多 50 个，创建每小时最多 20 次；修改密码接口每 15 分钟最多 10 次。
- 登录对不存在的用户同样执行 bcrypt，避免通过响应时间枚举用户名。
- 生产环境（Secure Cookie）会话 Cookie 改名为 `__Host-pf_session`，防止同级子域覆盖。**升级后已登录用户需要重新登录一次。**
- 供应商文件下载额外拦截 `100.64.0.0/10`（含阿里云元数据地址 `100.100.100.200`）等非公网地址。

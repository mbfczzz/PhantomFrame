## 检查中修复的问题

| 风险或缺陷 | 修复与验证 |
|---|---|
| 同供应商多条路由串用密钥、旧模型密钥覆盖路由密钥 | 每条独立存储；任务快照固定；缺失凭据不向父供应商或旧模型配置借用 |
| 未定价模型误调用或同名价格误继承 | 类型／名称／规格校验，歧义待定；无价与停用价提交测试均不建任务、不扣款 |
| 重复导入重置人工审核或重启覆盖后台修复 | 已有价格与参数保留；启动指纹检查；显式导入仍按 CSV 应用路由字段 |
| 非方形图片尺寸错误 | 对照参考适配器校准像素表，保留各供应商自己的限制 |
| Runware 参数未生效 | 修正参考素材嵌套字段、质量配置、图片面积上限、视频部分比例及 480p 尺寸 |
| Midjourney 版本和高清档位未发送 | 固定版本与 SD/HD，限制可选档位，阻止提示词覆盖收费相关选项 |
| AtlasCloud 选择高清仍发送普通档 | 分辨率 2k 对应 hd=true；移除不支持的 4k 选项 |
| 表单展示了上游忽略的选项 | 收紧 DSAS、Midjourney、音乐和音效参数；保留有实际协议映射的字段 |
| 空错误对象导致正常异步任务失败 | 区分空对象、零错误码与实际嵌套错误；补充 fail/cancel 状态 |
| 某些响应无法提取最终文件 | 支持嵌套 resultJson、resultUrls、同源相对结果路径；过滤声明为其他媒介的封面 |
| 未完成结果或其他任务响应被接收 | 处理中不直接接受输出；检查包括 data.id 在内的任务标识 |
| 数字任务 ID 精度丢失 | JSON UseNumber 保留大整数任务标识 |
| 文件类型与任务不一致 | 按内容识别 MIME，不把图片当音频／视频保存为成功结果 |
| 文本被执行或复制不完整 | 按纯文本渲染，保留完整文本；切换请求时忽略已取消的响应 |
| 路由状态忽略供应商总开关 | 列表展示供应商停用状态；报价检查供应商、路由及模型开关 |

## 验证证据

测试使用独立 MySQL 3307、Redis 6380 和随机测试数据库／Redis 前缀；上游由 localhost HTTP 模拟，外部 HTTP 代理指向不可用本地端口。没有真实模型生成或真实付款调用，没有修改生产业务数据。

- 完整后端回归：62 个顶层用例、502 个 PASS 节点通过，约 104 秒。包括此前的积分、退款重试、权限、并发、幂等、日志脱敏与支付相关测试。记录：`test-results/inventory-final-backend.log`。
- 随后的启动导入保护等增量改动再次通过供应商／鉴权定向测试：`test-results/inventory-final-targeted.log`。
- 清单逐路由请求计划校验：249 条；HTTP 模拟协议用例：57 个，覆盖 34 家供应商。
- 新类型端到端：图片、视频、文本、音频、超分的建单、工作进程、结果归属、扣费、失败退款、删除后幂等重放。
- 新界面流程：CSV 预览与导入、密钥不回显、文本不执行 HTML、音频与超分播放器、一次扣费，以及桌面／手机和明暗主题。记录：`test-results/inventory-new-ui.log`，截图：`test-results/inventory-ui/`。
- 界面审计：138 个页面／主题／视口组合、46 项对比度扫描通过，包括请求异常、未知提交结果对账、登出失败和分页恢复。记录：`test-results/inventory-audit-ui.log`。
- 原有 UI 工作流与跨标签页余额保护再次回归。记录：`test-results/inventory-baseline-ui.log`、`test-results/inventory-recheck-ui.log`。
- TypeScript/Vite 与 Go 构建、`go vet ./...`、`git diff --check` 通过。
- 原 CSV 的 51 个不同凭据值扫描可提交源文件，未发现匹配；扫描报告不含密钥：`test-results/inventory-secret-scan.json`。

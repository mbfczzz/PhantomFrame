# 供应商实例与接入协议

2026-10-28 起，生产入口使用「协议 → 供应商实例 → 支持模型目录 → 模型管理」架构。协议定义调用方式，供应商实例保存独立的地址与凭据；不再自动建立 34 家供应商和 249 条固定模型路由，也不再自动新增 OpenCrow 渠道。

## 配置步骤

1. 在「渠道管理」点击「新增渠道」，选择接入协议。原清单的 34 家供应商专用协议、OpenCrow 及原有兼容协议均保留。
2. 填写渠道名称、API 地址及 API Key。同一协议可创建多个实例，例如「APIYI 主账号」「APIYI 备用账号」。实例 ID、密钥、支持模型目录和发布模型互相独立。
3. 需要拉取模型时填写「模型列表接口路径」。系统只发送 GET 目录请求，携带本实例 Key，支持 JSON 数组、`data` 数组及 `models` 数组。默认路径是可修改的目录入口，不代表上游一定开放该接口；不支持或鉴权失败时可手动添加。
4. 在卡片点击「管理模型」。提供目录的渠道点击「拉取模型列表」；没有目录的点击「添加支持模型」，填写实际的上游模型 ID、显示名和类型。
5. 专用协议手动添加时默认生成该协议对应的参数定义。必要时可关闭「使用协议默认参数」自行编辑；模型协议选项可以指定 `sourceModel`、`chatAPI`、`submit_path_override`、`poll_path_override`。这些选项用于已适配接口的差异，不会凭空实现新的生成协议。
6. 将支持模型发布到模型管理，核对参数并配置售价，再启用。新发布模型默认停用，不会凭上游目录虚构售价，未定价模型不能调用。

同一个上游模型可分别存在于多个供应商实例中，发布后使用不同的站内模型 ID。重复拉取不覆盖已审核条目，也不自动发布或删除未返回的模型。可选的模型独立 Key 仅覆盖当前实例下该模型，其他模型仍使用实例默认 Key。

同一个实例同时只能执行一次模型拉取，重复请求返回正在拉取的提示；不同实例仍可并行。拉取及目录写入共用 20 秒超时，超时或取消会回滚尚未提交的目录数据并释放同步锁，可重新尝试。

更换 API 基础地址或生成调用配置会停用该供应商的关联模型，价格保留，需核对后重新启用。仅修改名称、轮换 Key、调整模型目录路径或轮询间隔不会误停用模型。指定的公共素材上传服务和轮询配置会随专用协议保留；提交时同时保存所选上传服务的地址和加密凭据快照，后续修改不会把已有任务切到另一个上传账号。

图片、视频、文本、音频及视频超分继续使用已有适配器；类型受所选协议支持范围约束，添加、发布和报价均校验，3D 不接入。上游目录未知类型的模型可先确认类型再发布。调用日志与计费仍按实际供应商实例区分。

## 已授权的一次性旧目录清理

本次升级按用户确认，首次启动执行迁移 `provider-instances-reset-v1-20261028`：

- 清空旧供应商账户配置、独立路由与密钥、支持模型目录、已发布模型及售价。
- 保留用户、管理员、余额、流水、订单相关业务数据、素材、项目、生成任务和调用日志。
- 为旧任务补齐模型名称与类型快照，并解除任务对当前模型表的外键依赖，使历史在旧模型删除后仍可查询。
- 已排队或运行中的任务继续使用提交时的加密凭据快照；旧版本未保存上传服务快照的任务，在清理前补齐上传服务依赖。已结束任务移除快照中的主调用密钥及上传服务凭据，保留历史展示数据。
- 迁移完成后记录版本标记。后续重启不再清空新建供应商、模型或价格。

新的 API 服务不再挂载旧「供应商路由」管理入口，旧地址跳转到渠道管理；`PROVIDER_INVENTORY_FILE` 不再自动导入，旧 CSV 导入命令也不会重新建立旧架构。原 CSV 可供管理员对照填写账户，不能依靠重新导入恢复旧管理数据。

## 密钥与删除

供应商卡片可直接进入 Key 配置，管理员点击眼睛查看当前实例的完整 Key。默认隐藏、关闭窗口清理显示；只查看后保存不会回写旧 Key，只有手动编辑才替换。普通用户及 API Token 不能读取管理密钥。

保存时清理 Key 首尾空白，拒绝内部空白与控制字符；专用协议和 OpenCrow 同时拒绝明显无效的占位 Key。该格式检查不会调用上游，也不能证明账号余额或授权有效。

专用协议供应商在没有关联任务时可一并删除其目录、模型、售价和密钥；有任务记录时请停用，保留历史关联。普通兼容协议沿用先处理已发布模型再删除的规则。

本次开发验证只使用隔离数据库与模拟上游，没有验证真实供应商的余额、账号权限或在线服务可用性。服务器上的清理发生在部署本版本并首次启动时，不是在本地修改代码时。

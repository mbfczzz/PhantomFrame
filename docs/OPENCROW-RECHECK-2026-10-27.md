# OpenCrow 接入复查（2026-10-27）

本轮在上一轮尚未提交的 OpenCrow 接入代码上继续检查，保留全部既有修改。只读取官方公开文档和运行本地模拟测试，没有调用真实模型、支付接口或生产数据库。

## 新发现与处理

| 问题 | 影响 | 修复 |
|---|---|---|
| 动作控制只检查时长，没有检查图片／视频格式与尺寸 | 明显不合格的素材可能先预扣再被上游拒绝 | 在报价和提交阶段检查 PNG/JPEG 图片尺寸及比例、MP4 视频尺寸与人物朝向对应时长；读取失败即拒绝，不产生任务或扣费 |
| 数据库中的模型参数被删改后，原生必需字段可能缺失 | 可能向上游提交空分辨率、零时长等无效参数 | 校验 OpenCrow 原生规格字段是否完整；必填音色不接受纯空白；错误信息指向实际存在的模型管理入口 |
| 参考素材字段被管理员误设为其他类型 | 例如本应传图片的编辑接口可能收到视频 | 用适配器定义与数据库素材真实类型再次核对，防止只依赖可编辑表单定义 |
| 临时 HTTP 错误带有明确已受理的任务回执时，响应体被丢弃 | 上游可能继续生成，但本站提前判失败且丢失查询机会 | 仅对 OpenCrow 视频的临时 HTTP 错误解析有界 JSON；验证任务 ID、模型、状态和业务错误后继续查询原任务，不重发 POST |
| 公开任务 ID 与内部上游 ID 同时出现时可能选错 | 查询了错误的标识，或把内部 ID 不同的正常结果误判为其他任务 | 以顶层公开任务 ID 为准，保留网关和内部模型 ID 的不同语义 |
| 无顶层任务 ID 的数组响应没有按子任务标识筛选 | 明确属于其他任务的输出可能被当成当前结果 | 匹配 `data[]` 中的任务标识，只接收当前任务的数据；不匹配时继续查询 |

动作素材限制重新核对了 OpenCrow 官方公开的 `kling-video-motion-control-v3.0` 文档。此次还尝试读取 Seedance 2.5、HappyHorse 1.1 R2V、Qwen Audio 3.1 TTS 的独立模型文档，接口未提供可用专页；没有因此猜测新的参数或扩大已实现的功能范围。现有同系列基础适配仍需以真实账号的可用模型、供应商规则为准。

## 验证结果

- 全量后端：**78 个顶层测试、960 个 PASS 节点**通过，约 210 秒。包含原有计费、退款、权限、幂等、155 个 OpenCrow 模型参数计划、原供应商路由协议等测试。
- 新增前置拦截：缺分辨率、缺时长、错误参考素材类型、纯空白音色，均返回错误且没有创建任务或改变余额。
- 新增动作素材边界：合法素材、图片过小、图片比例超限、错误图片格式、视频尺寸过小、错误视频格式、11 秒视频在 image 朝向被拒绝、在 video 朝向通过。
- 媒体校验使用本地生成的 PNG 和无 AI 内容的 MP4 黑色视频样本，并实际调用 ffprobe 读取元数据。
- 异常任务链路：模拟提交返回 HTTP 503，但携带有效已受理回执；随后返回其他任务结果，再返回当前任务结果。最终只提交一次、只下载当前任务一次、只扣费一次。
- 额外验证：拒绝无状态／非法任务 ID／模型不符／包含业务错误／多个 JSON 拼接的异常回执；顶层公开 ID 和内部上游 ID 不同的正常结果不误杀。
- 浏览器：原 OpenCrow 新增、同步、发布、视频生成流程通过；补充验证小尺寸动作图导致明确错误、生成按钮禁用、余额不变、没有新增上游请求。手机截图检查通过，无页面脚本错误。
- 本地前端与 Go 重新构建通过，`go vet ./...`、`git diff --check` 通过。真实 CSV 的 51 个不同凭据值扫描未匹配可提交源文件。

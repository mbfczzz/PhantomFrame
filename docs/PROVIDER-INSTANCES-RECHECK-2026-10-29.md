# 供应商实例架构复查（2026-10-29）

本轮重点检查配置隔离、参考素材上传、旧任务迁移和模型重新审核，发现并修复以下问题。

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| 专用协议转换丢失运行配置 | `uploadProviderId` 和 `pollInterval` 被丢弃，指定的上传服务可能被默认服务取代 | 保留实例运行配置，再叠加协议及模型映射，使用独立上传服务的配置不再串用 |
| 排队任务仍依赖当前上传服务表 | 升级清空旧供应商后，带参考素材的排队任务无法上传；后续轮换上传 Key 也会改变旧任务使用的凭据 | 新任务保存上传服务快照；迁移在清理前为旧排队／运行任务补齐依赖。原来没有可用上传服务的任务不会借用后来创建的其他账号 |
| 协议选项规范化未落库 | 例如 `chatAPI` 在校验时去掉空格，但原值仍被保存，运行时可能选择错误接口 | 保存经过规范化的字段，同时保留无关的运行配置 |
| 修改生成绑定后模型仍可调用 | 更换实例地址或生成接口配置后，已启用模型直接使用新绑定，未重新核对价格和规格 | 停用关联模型并保留售价。名称、密钥轮换、目录路径、末尾斜杠规范化等非绑定变化不会误停用 |

# PhantomFrame 产品界面

当前版本保留已验证的顶部导航和首屏操作区，配色按用户偏好回到参考站的中性黑灰、亮绿、玫红和金色。业务功能、账户、模型、价格和供应商配置继续使用现有实现。

## 视觉语言

金额统一显示人民币：`money()` 输出 `¥30`、`¥0.1`、`¥0.108`，流水保留正负号，整数不补小数。1 积分对应 ¥1。模型与参考素材单价最多六位小数，整笔费用在相加后四舍五入到分；兑换码、调账、转账和赠送额度仍最多两位小数。报价展示生成与素材费用明细，参考视频由服务端读取真实时长。API 的 `credits` 字段保持兼容，单位为 CNY。

- 名称：幻帧 / PhantomFrame。导航优先使用简洁的中文名称。
- 标识：`public/brand-mark.svg`，以 F 与取景边框构成的原创几何标识。
- 主图：`public/images/login-light-study.jpg`，Henry Fraczek 的黑白建筑摄影，来源与许可见 [视觉资源说明](VISUAL_ASSETS.md)。前一版星云主图保留为未使用的历史资源。
- 配色：中性黑背景 `#101113`、炭灰面板 `#1a1b1f`、输入面 `#202125`、正文 `#f5f6f7`。主操作用亮绿 `#22c55e`，视频标签用玫红 `#f20d7a`，金额用金色 `#f5c84b`。登录按钮使用稍深的玫红以保证白字对比度。
- 背景与面板保持中性黑灰，去除偏青绿底色、背景彩光和点阵。通过微弱灰阶渐变、细描边与阴影区分层次；保留局部交互反光，品牌与页面结构独立维护。
- `src/palette.css` 是全站颜色的单一来源，统一定义深浅主题及语义颜色；悬停、描边和标签底色从对应颜色派生，避免深浅主题混用旧色值。普通辅助入口使用灰色，交互时才强调。
- 浅色备选：背景 `#f4f5f6`、白色面板、主操作绿 `#15803d`；深色主题按钮使用深色文字，浅色主题使用白字。
- 动效：桌面编辑卡片随指针呈现局部边缘反光；输入聚焦显示绿色描边；按钮悬停时单次扫光并轻微上移，导航与浮层短暂淡入。没有循环装饰动画；手机关闭随动光，系统开启减少动态效果时关闭这些动画。`useSurfaceLight` 通过单帧合并更新 CSS 变量，离开、卸载及偏好切换时清理监听与动画帧。
- 在已确认的配色上，根据两站实测对比完善首屏构图、控件、参考素材与结果预览；登录摄影继续保留。
- 简化品牌和导航，移除无实际切换能力的工作区卡片、装饰性序号、英文眉题、泛化宣传语和重复示例卡片。成功与失败仍保留有明确意义的状态颜色。
- 登录输入框与按钮文字 16px、登录按钮高度 48px；工作台提示词 15px（手机 16px），辅助文字通常 12–13px。

## 结构

`src/components/Shell.tsx` 使用顶部横向导航，品牌放在左侧，主模块依次为「创作」「生成记录」「模型与价格」「资产库」「开放平台」，当前模块用细下划线标识。余额、主题和账户入口在右侧；第二行提供位置提示及「提交工单」「资金流水」「兑换充值」等服务入口。桌面没有固定左侧导航栏，也不使用原先的亮色胶囊选中项。

手机主模块位于顶部品牌栏下方，底部不再放导航。更多服务位于可展开的双列导航面板，支持 Escape、焦点约束、点击外部关闭，点击链接后自动收起。顶部余额跳转到独立充值页；账户入口移到右上角（手机为导航面板中的账户链接）。管理后台仍按角色权限开放。画布旧地址 `/canvas/*` 跳转到创作页，旧数据保留。

`src/pages/Support.tsx` 复用同一套列表、详情与对话组件实现用户工单和管理员工单管理，按身份使用不同 API；状态为待处理、待回复、已解决、已关闭。`src/pages/Billing.tsx` 提供资金流水和兑换充值页面，明确所有金额为人民币元，流水支持筛选、汇总与分页；兑换回执使用事务实际返回的到账额、余额和流水号。新增页面样式集中在 `src/services.css`，沿用既有深浅主题。

`src/pages/Developer.tsx` 是开放平台独立页面：提供可复制 API 地址、API 生成统计，以及「API 密钥」「快速接入」「调用记录」三个页签。密钥只在创建时显示完整值，支持立即撤销；代码示例只使用环境变量占位，不嵌入用户真实密钥。API 统计与调用记录由服务端按 `source=api` 筛选和分页，账户余额与网页创作共用。布局沿用现有深灰面板、绿色操作与金色金额，样式在 `src/developer.css`。

`src/pages/Studio.tsx` 使用「内容编辑 / 生成设置 / 结果画廊」三段结构。页标题左对齐，右侧按钮打开结果区。桌面左侧编辑卡片专注提示词，参考素材在输入区下方横向排列；右侧独立设置卡片包含类型、计费、模型、输出参数、报价和生成按钮。结果以多列卡片排列在两张卡片下方，不再使用右侧结果抽屉，也不再把所有控件装进一个横向圆角大框。

`src/components/Select.tsx` 提供统一深浅主题的下拉浮层、绿色选中项与勾选标记。模型选择支持搜索、渠道分组、说明和起步价格，参数选择使用相同组件。支持方向键、Enter、Escape、Tab 与焦点恢复；浮层根据视口调整位置，避免被面板裁剪。

参考素材默认打开紧凑的上传面板，支持选文件、拖放或进入资产库；提示词也支持直接粘贴图片。上传前检查类型、数量与 30MB 大小限制，上传中阻止生成和切换模型。已上传素材可预览，输入 `@` 或点击素材编号可插入引用；删除素材同步移除引用。切换模型保留其仍支持的素材，提交时将引用编号映射为实际参考顺序，随素材 ID 一起传入现有接口。

桌面卡片圆角 14px，手机 12px；设置卡片宽 290–320px，独立于提示词区域。手机改为单列内容与设置，详细参数可展开；底部固定报价和生成按钮，并为内容预留滚动空间。结果区默认折叠，提交后自动打开，关闭后焦点回到触发按钮。空态、排队、生成中、成功与失败均使用真实状态，不显示虚构百分比。

`src/pages/Auth.tsx` 使用约 1120 × 640px 的集中式面板，摄影与表单约为 55:45。摄影保留作者署名。错误信息直接显示在表单内，字段使用 aria-invalid 及关联提示；修改输入后清除旧错误。用户自定义副标题优先用于登录说明，系统默认宣传语不再展示。手机端缩短照片区域，让登录操作优先出现。

`src/palette.css` 定义全站配色，`src/styles.css` 与 `src/cinematic.css` 提供公共结构，`src/controls.css` 统一浮层、复选框、字体与弹窗，`src/composer.css` 定义编辑区、设置卡片与结果画廊，`src/layout.css` 定义横向导航和全宽工作空间。`src/finish.css` 负责材质、反光与交互动效。`src/components/PromptEditor.tsx` 负责提示词示例、粘贴与引用选择。

材质与交互设计参考本地 [UI Styles 技能](C:/Users/mbfczzzz/.mirasim/skills/ui-styles/SKILL.md) 的 Fluent 2 和 Mouse Tracking 风格说明，仅采纳分层表面和局部反光原则；保持项目自己的布局与绿色配色，不采用示例的视差倾斜、粒子拖尾和蓝紫主色。风格库来源：[UI-Prompt](https://github.com/TonnyWong1052/UI-Prompt)。

## 管理员后台

管理员在桌面右上角和手机导航菜单中可见「管理后台」，账户页保留原有入口。普通用户不渲染这些入口，直接访问 `/admin/*` 返回创作页。所有 `/api/admin/*` 接口均在 Go 服务端要求有效网页登录和 `admin` 角色；管理员的 API Key 也不能使用管理接口。

后台包括模型、参数、价格、渠道、用户、兑换码管理、工单、全站调用、全站流水、站点设置和操作日志。兑换码管理沿用账户余额账本：批量生成兑换码、设置单张额度与到期时间、复制或导出本批、查询兑换人和使用时间。可兑换、已使用、已过期状态由服务端计算，已使用的码不可删除。

价格配置归入「模型管理」。模型编辑窗口提供「基本信息 / 计费规则」两个页签；渠道模型发布后可直接进入价格配置。模型列表中的「配置价格」可直接打开规则页签，新增和编辑价格时固定所属模型。旧 `/admin/prices` 页面地址跳转模型管理；价格数据和管理员接口继续使用既有实现。

新模型入口改为「从渠道发布」：渠道卡片显示支持/已发布数量，打开 `ProviderModels` 管理该渠道的模型清单。手动添加与接口拉取得到的条目先保存在 `provider_models`；只有显式发布才创建业务 `models` 记录，初始停用、不预设价格，之后由管理员配置并启用。站内模型 ID 与上游 ID 分开维护，发布后的渠道绑定在编辑表单中固定。

发布使用 MySQL 渠道行锁保证幂等，同渠道同上游模型重复发布返回已有模型，不覆盖价格和参数；全站 ID 冲突返回 409。已有业务模型启动时补建渠道关联，保留原数据，历史同渠道同上游的多个别名会全部显示管理链接。渠道拉取只追加新 ID；不自动发布、不删除已有条目、不覆盖已配置模板。删除业务模型后，渠道条目恢复待发布；已有调用的业务模型仍按原规则禁止删除。

「基本信息」中的 `ReferenceSettings` 直接编辑同一份参数定义，支持分别启用图片、视频、音频；每个上传字段的数量上限留空时移除 `max`，0 禁止添加，正整数为上限。没有隐含的 6/9 个默认值。「高级参数配置」保留 JSON 编辑，双方同步，普通参数名称、默认值、选项和范围均由后台定义。

`src/model-config.ts` 为模型卡片、详情和创作页提供统一的数量与文案。同类多个素材字段汇总显示，任一字段无上限时显示不限；分配时先满足必填/最小数量，再填充其他字段。创作页重新获得焦点会读取最新参数，清理超限素材及其提示词引用；资产选择器按剩余数量禁用超量选择。Go 服务在报价及提交时独立校验，空上限不限制，0 不放行；素材所有权采用分批查询以支持较多引用。

全站调用包含所有用户的网页/API 生成任务，可按用户、模型、类型、来源、状态和 UTC 日期筛选，并查看任务详情与输出。记录、兑换码、流水和操作日志均在服务端分页，不再截断到最近 500/300 条。管理员生成文件预览使用独立受保护的 `/api/admin/jobs/{id}/outputs/{assetID}`；用户素材接口继续限制所有权，上游密钥不会出现在记录返回值中。

`internal/api/admin_records_test.go` 验证接口权限、跨用户查看、文件访问隔离、超过 500 条的分页、筛选和兑换状态。`scripts/review-admin.mjs` 只读取现有数据，检查后台页面与手机入口。

## 弹窗与子页面

`src/workspace.css` 统一子页面的标题分隔、筛选栏、表格、统计卡片、空状态以及弹窗排版。沿用已确认的黑灰、亮绿、玫红和金色配色。

公共 `Modal` 支持图标与说明，渲染到 document.body，长内容在弹窗内部滚动，`.modal-footer` 固定在滚动区域底部；手机端靠下显示并保留视口边距。默认聚焦第一个可编辑字段，关闭后恢复触发点。嵌套弹窗使用栈管理焦点、inert 与页面滚动锁，Escape 只关闭最上层。

`ConfirmProvider` / `useConfirm` 替代业务页和后台中的原生确认框。取消、点击外部与 Escape 均返回 false；默认聚焦取消，明确确认后才执行删除、撤销或权限变更。后台账户角色等接口权限仍由服务端验证。

生成记录、资产库和工单列表区分首次空状态与筛选无结果，后者提供清空筛选。工单新建页补充问题详情标题与查询入口；模型详情将价格条件翻译成参数标签，API 示例默认折叠。账户与开放平台表单统一使用取消/提交操作区。

`node scripts/review-workspace.mjs` 检查主要子页面及弹窗的深浅主题、1440 / 390 / 320px 适配、长表单操作区、默认焦点和筛选重置；只读取业务数据并取消所有确认操作。`npm run test:ui` 在隔离数据库中验证真实提交、确认/取消、嵌套焦点和账务流程。

## 首屏验收

运行 `node scripts/review-cinematic.mjs` 验证首屏尺寸，运行 `node scripts/review-creation-controls.mjs` 检查展开的菜单、上传面板和结果预览。`npm run test:ui` 同时验证模型搜索、键盘交互、直接上传、粘贴、拖放、素材引用的真实提交及原有业务流程。

- 同时验证图片与视频模式。
- 验证 1440×1000、1440×900、1366×768、1024×768、768×1024、390×844、390×740、360×640、320×568。
- 生成按钮必须完整位于首屏，手机端固定在底部操作栏，内容需要预留相应滚动空间；参数入口不能被操作栏遮挡。
- 登录按钮必须位于首屏；输入框和按钮字体达到 16px，主图实际加载。
- 页面无横向溢出、无浏览器脚本错误，同时验证浅色主题可用。

当前常规桌面尺寸中生成按钮底部约 714–733px；320×568 小屏中按钮底部约 556px。还需验证结果画廊位于编辑区与设置区下方、两者不重叠，以及横向导航在桌面和手机上均完整可用。

## 兼容与数据

旧版 Node 服务曾执行一次性 `independent-studio-brand-v2` 品牌迁移。当前 Go + MySQL + Redis 版本通过 `cmd/migrate` 导入旧业务数据和迁移记录，保留用户配置的站点信息；新数据库默认使用 PhantomFrame。

当前主题偏好使用 `pf-cinematic-theme-v3`；没有显式偏好时默认深色。仅在用户点击主题按钮时保存偏好，避免开发热更新把前一版的浅色默认值带入新版。

React Flow 等依赖的许可和画布署名继续保留。业务参考来源保留在项目说明中；视觉独立性不代表对法律状态作出保证。
